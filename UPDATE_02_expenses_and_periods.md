# Оновлення 2 — Огляд за періодами, Витрати, Чистий/Грязний прибуток

## Що нового

1. **Огляд** тепер має перемикач періоду: **День / Тиждень / Місяць / Рік / Весь час**.
   Усі цифри (дохід, к-сть авто, середній чек, витрати, виплати
   працівникам, прибуток) перераховуються під обраний період.

2. **Нова вкладка "Витрати"**:
   - Додавання витрати: категорія (Витратні матеріали, Зарплата, Оренда,
     Комунальні послуги, Ремонт обладнання, Реклама, Інше), сума, дата,
     нотатка.
   - Той самий перемикач періоду День/Тиждень/Місяць/Рік/Весь час.
   - Розбивка витрат за категоріями збоку.

3. На "Огляді" додано:
   - **Грязний прибуток** — весь дохід до будь-яких вирахувань.
   - **Чистий прибуток** — дохід мінус виплати працівникам мінус витрати
     (стає червоним, якщо від'ємний).

4. У "Робочому дні" ручне поле "Витрати за день" прибрано — тепер витрати
   вводяться тільки у вкладці "Витрати", а тут просто показується
   автоматична сума за обрану дату.

5. У бічному меню під назвою мийки більше не показується email.

## Крок 3. Перевір локально

```bash
npm run dev
```

1. Зайди у "Витрати" → додай кілька витрат різних категорій і дат.
2. Зайди в "Огляд" → поперемикай День/Тиждень/Місяць/Рік/Весь час і
   переконайся, що цифри дохід/витрати/прибуток міняються.
3. Перевір, що "Чистий прибуток" = Дохід − Виплати працівникам − Витрати.
4. Перевір "Робочий день" — витрати там тепер показуються автоматично.
