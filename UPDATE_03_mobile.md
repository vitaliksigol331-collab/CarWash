# Оновлення 3 — Мобільна та планшетна адаптація

## Що змінилось

Цей архів також містить усі попередні виправлення з нашого чату
(стрілки дати в "Робочому дні", графік доходу в "Огляді", "Рентабельність"
замість дубля "Грязний прибуток", нові послуги "Мийка килимків" і
"Мийка двигуна"). Якщо ти вже вносив ці правки вручну через консоль —
нічого страшного, цей архів просто містить той самий фінальний результат.

### Мобільна адаптація

1. **Таблиці з даними** (список авто в "Робочому дні", список витрат у
   "Витратах") тепер на телефонах і невеликих планшетах показуються як
   картки одна під одною замість таблиці з горизонтальним скролом.
   На великих екранах (від планшета в альбомній орієнтації і ширше) —
   як і раніше, таблиця.

2. **Заголовки вкладок** (кнопка "Додати...", перемикач періоду) на
   мобільному тепер стають на весь рядок під назвою вкладки, а не
   тиснуться поруч.

3. **Перемикач періоду** (День/Тиждень/Місяць/Рік/Весь час) отримав
   горизонтальний скрол про запас — якщо на дуже вузькому екрані кнопки
   не влізуть в рядок, з'явиться легкий свайп замість переносу чи
   обрізання.

4. **Картки статистики** — цифри й підписи тепер адаптивного розміру
   і не "вилазять" за межі картки на малих екранах.

5. **Перемикач дати** в "Робочому дні" тепер компактніший на телефоні.

6. Додано підтримку "вирізу" на iPhone (safe area) — контент не ховається
   під динамічний острівець чи смугу жестів знизу.

7. Додано мета-теги, щоб при додаванні сайту на головний екран телефону
   (через "Поділитись → На екран Домівки") він виглядав охайніше — з
   правильним кольором статус-бару.

## Крок 1. Заміни файли

Розпакуй цей архів і заміни ним свою папку `carwash-saas` повністю.

⚠️ **Обов'язково збережи свій `.env`** зі справжніми ключами Supabase
перед заміною — постав його назад у нову папку після розпакування.

## Крок 2. База даних — без змін

Ця частина оновлення стосується тільки вигляду інтерфейсу, жодних нових
SQL-міграцій виконувати не потрібно.

## Крок 3. Встанови й запусти

```bash
cd /шлях/до/нової/carwash-saas
npm install
npm run dev
```

## Крок 4. Перевір на телефоні по-справжньому

Найкраще перевірити не просто звуженням вікна браузера, а на реальному
пристрої:

1. У терміналі після `npm run dev` подивись рядок **"Network:"** —
   там буде адреса типу `http://192.168.х.х:5173`
2. Переконайся, що телефон підключений до **того самого Wi-Fi**, що й
   комп'ютер
3. Відкрий цю адресу в браузері телефону

Або простіше — почекай, поки задеплоїш на Vercel, і відкрий продакшн-URL
прямо на телефоні.

Пройдись по всіх вкладках: "Огляд", "Робочий день" (додай авто, полистай
дати), "Працівники" (відкрий картку), "Витрати", "Склад", "Клієнти",
"Запис" — переконайся, що ніде нічого не обрізається і не вилазить за
межі екрана.
