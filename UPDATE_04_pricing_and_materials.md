# Оновлення 4 — Прайс-лист зі знижками + автосписання складу

## Що нового

### 1. Прайс-лист за типом кузова, зі знижками/надбавками

У "Робочому дні" з'явилась кнопка **"Прайс-лист"** поруч із "Додати авто" —
там задаєш базову ціну для кожної комбінації послуга + тип кузова
(наприклад, "Комплексне миття" + "Кросовер" = 350 ₴).

Коли додаєш авто і обираєш послугу та тип кузова — ціна підставляється
сама. Але поле ціни **завжди залишається редагованим**: якщо треба
знижка постійному клієнту чи навпаки дорожче через сильний бруд — просто
зміни цифру вручну. З'явилось також необов'язкове поле **"Нотатка до
ціни"** — можна лишити коментар типу "знижка 10%, постійний клієнт", щоб
потім не забути, чому ціна відрізняється від прайсу.

### 2. Автосписання матеріалів зі складу

У вкладці **"Склад"** знизу з'явилась секція **"Списання матеріалів на
послуги"**. Там прив'язуєш: яка послуга витрачає який матеріал і в якій
кількості (наприклад, "Комплексне миття" → "Автошампунь" → 0.3 л за одне
авто).

Після цього — щоразу, коли в "Робочому дні" додаєш авто з такою
послугою, потрібна кількість матеріалу **автоматично зменшується** на
складі. Якщо випадково видалиш запис про авто — списане повертається
назад (щоб залишки не "з'їхали" через помилкове додавання).

Це працює через тригер у самій базі даних (як і синхронізація доходу
раніше) — тобто рахується миттєво і надійно, без затримок.

## Крок 1. Онови базу даних у Supabase

Виконай у **SQL Editor** файл `supabase/migration_04_price_and_materials.sql`.
Він також додає:
- поле "посада" для працівників,
- поле "щоденна ціль" для мийки,
- поле "джерело коштів" для витрат (каса мийки / особисті кошти) —

ці три речі поки що не мають інтерфейсу в цьому оновленні, з'являться
наступним кроком (я вже підготував для них місце в базі, щоб не робити
ще одну міграцію пізніше).

⚠️ Виконай попередні міграції (`migration_02`, `migration_03`), якщо ще
не робив цього.

## Крок 2. Онови файли проєкту

Заміни файли своєї папки `carwash-saas` вмістом цього архіву (збережи
`.env` і папку `.git` — не видаляй їх).

Змінені файли:
```
src/components/tabs/WorkDay.jsx     — прайс-лист, автопідстановка ціни, нотатка
src/components/tabs/Warehouse.jsx   — секція автосписання матеріалів
supabase/migration_04_price_and_materials.sql — НОВИЙ
```

## Крок 3. Перевір локально

```bash
npm run dev
```

1. У "Робочому дні" натисни "Прайс-лист" → задай кілька цін → збережи.
2. Додай авто з тією ж послугою/кузовом — переконайся, що ціна
   підставилась сама. Зміни її вручну — переконайся, що тепер вона не
   "перезаписується" назад.
3. У "Складі" прив'яжи матеріал до послуги (наприклад, шампунь до
   "Комплексне миття", 0.3 л).
4. Додай авто з цією послугою в "Робочому дні" → перевір, що кількість
   шампуню на складі зменшилась.
5. Видали цей запис про авто → перевір, що кількість повернулась назад.
