# AquaBoard — SaaS-платформа для автомийки

Фундамент проєкту: авторизація, темний дешборд, 5 робочих вкладок з реальним
збереженням даних у Supabase. Нижче — покрокова інструкція запуску з нуля.

## Що вже зроблено

1. **Авторизація** — реєстрація (email, пароль, назва мийки) та вхід.
2. **Layout дешборду** — темна тема, бічне меню, адаптивність під мобільні.
3. **Навігація без перезавантаження** — "Огляд", "Робочий день", "Склад",
   "Клієнти", "Запис" перемикаються станом React, без React Router.
4. **База даних Supabase** — усі дані прив'язані до `store_id` конкретної
   мийки і зберігаються назавжди. RLS гарантує, що кожен власник бачить
   лише свої дані.
5. **Функціонал кожної вкладки** — додавання, редагування, видалення,
   графік доходу, сповіщення про малі залишки на складі.

## Крок 1. Встанови залежності

Потрібен Node.js версії 18+ (перевір: `node -v`).

```bash
cd carwash-saas
npm install
```

## Крок 2. Створи проєкт у Supabase

1. Зайди на [supabase.com](https://supabase.com) → **New project**.
2. Обери назву, пароль для бази даних, регіон (найближчий до твоїх клієнтів,
   наприклад Frankfurt для України) → **Create new project**. Зачекай ~2 хв.
3. Зайди в **Project Settings → API**. Скопіюй:
   - `Project URL`
   - `anon public` ключ

## Крок 3. Підключи проєкт до Supabase

У корені проєкту скопіюй `.env.example` в `.env`:

```bash
cp .env.example .env
```

Відкрий `.env` і встав свої значення:

```
VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

⚠️ Файл `.env` вже в `.gitignore` — ключі не потраплять у git.

## Крок 4. Створи таблиці в базі даних

1. У Supabase зайди в **SQL Editor → New query**.
2. Відкрий файл `supabase/schema.sql` з цього проєкту, скопіюй **весь**
   вміст і встав у редактор.
3. Натисни **Run**.

Це створить:
- таблиці `stores`, `profiles`, `work_days`, `warehouse_items`, `clients`, `bookings`;
- тригер, який **автоматично** створює мийку (store) і профіль одразу
  після реєстрації нового користувача (назва мийки береться з форми
  реєстрації);
- Row Level Security — політики, які гарантують, що власник бачить і може
  редагувати лише дані **своєї** мийки. Це критично важливо для SaaS,
  де кожен клієнт має бачити тільки свої дані.

## Крок 5. Вимкни (або залиш) підтвердження email

За замовчуванням Supabase вимагає підтвердження email після реєстрації.

- **Для швидкого тестування:** Authentication → Providers → Email →
  вимкни "Confirm email".
- **Для продакшену:** залиш увімкненим, це безпечніше — просто налаштуй
  Email-темплейти пізніше (Authentication → Email Templates).

## Крок 6. Запусти проєкт локально

```bash
npm run dev
```

Відкрий [http://localhost:5173](http://localhost:5173). Зареєструй першу
мийку — назва, email, пароль. Якщо підтвердження email вимкнено, одразу
побачиш дешборд.

## Структура проєкту

```
carwash-saas/
├── src/
│   ├── lib/supabaseClient.js       — підключення до Supabase
│   ├── context/AuthContext.jsx     — сесія, профіль, sign in/up/out
│   ├── pages/
│   │   ├── Login.jsx               — вхід
│   │   ├── Register.jsx            — реєстрація
│   │   └── Dashboard.jsx           — layout з Sidebar + контент
│   ├── components/
│   │   ├── Sidebar.jsx             — бічне меню навігації
│   │   ├── ui.jsx                  — спільні UI-елементи (кнопки, картки, модалки)
│   │   └── tabs/
│   │       ├── Overview.jsx        — статистика + графік доходу
│   │       ├── WorkDay.jsx         — облік робочих днів
│   │       ├── Warehouse.jsx       — склад матеріалів
│   │       ├── Clients.jsx         — база клієнтів
│   │       └── Booking.jsx         — запис/бронювання
│   └── App.jsx
└── supabase/schema.sql             — вся структура бази одним файлом
```

## Дизайн-система

- **Фон:** глибокий чорнильно-синій (`#0B1220`), не чистий чорний — м'якше для очей.
- **Акценти:** аква-блакитний (`#22D3EE`) і піняво-зелений (`#34D399`) — асоціація з водою й піною; бурштиновий і кораловий — для попереджень і фінансових акцентів.
- **Типографіка:** Manrope (заголовки, geometric-sans) + Inter (текст) + JetBrains Mono (цифри й статистика — легше зчитувати суми).
- **Сигнатурний елемент:** вертикальна лінія-індикатор активної вкладки з градієнтом аква→піна, і легке "світіння" (glow) навколо карток статистики.
