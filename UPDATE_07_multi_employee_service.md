x1# Оновлення 7 — Кілька працівників + кілька послуг на одне авто

## Що нового

### 1. Кілька працівників на одне авто

У "Робочому дні" замість вибору одного працівника тепер список із чекбоксами —
можна відмітити 2, 3 і більше. **Кожен обраний працівник отримує свій
власний % від загальної ціни авто** (не поділ одного відсотка між усіма,
а кожен — свій повний відсоток, як і завжди).

### 2. Кілька послуг на одне авто

Тепер можна відмітити одразу кілька послуг для одного авто — наприклад,
**"Комплексне миття" + "Мийка двигуна"**. Для кожної обраної послуги
з'являється своє поле ціни (підставляється з прайс-листа автоматично,
можна відредагувати). Загальна ціна авто — це сума всіх обраних послуг,
показується окремим рядком у формі.

"Мийка килимків" і далі працює через калькулятор площі (довжина × ширина
× ставка), просто тепер це один з можливих пунктів у списку послуг, а не
єдиний вибір.

### 3. Що це змінює технічно (для розуміння)

- Дохід і кількість авто на "Огляді"/"Робочому дні" рахуються так само,
  як і раніше.
- **Виплати працівникам** на "Огляді" й "Робочому дні" тепер правильно
  враховують ситуацію, коли кілька людей працювали над одним авто (раніше
  технічно було можливо вказати лише одного).
- **Автосписання складу** тепер списує матеріали окремо за кожну обрану
  послугу авто (якщо авто мало 2 послуги, і обидві прив'язані до різних
  матеріалів — спишеться і те, і те).
- Стара історія (записи, зроблені до цього оновлення) автоматично
  переноситься в нову структуру міграцією — нічого не губиться і не
  дублюється.

## Крок 3. Перевір локально

```bash
npm install
npm run dev
```

1. "Робочий день" → "Додати авто" → відміть **дві послуги** (наприклад,
   Комплексне миття + Мийка двигуна) → перевір, що загальна ціна = сума
   обох.
2. Відміть **двох працівників** → збережи → перевір, що обидва бачать
   виплату у списку авто.
3. "Огляд" → перевір, що "Виплачено працівникам" враховує обох.
4. "Працівники" → відкрий картку кожного з двох працівників → перевір,
   що це авто з'явилось в обох.
5. Якщо у тебе прив'язані матеріали до обох обраних послуг у "Складі" —
   перевір, що залишки зменшились за кожною послугою окремо.
